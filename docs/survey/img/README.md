# Survey thumbnails

Resized (640 px) KartaView photos, licensed **CC BY-SA 4.0** by their KartaView
contributors. Each file's KartaView photo id and sequence id are listed in
`../stimuli.json`; the original is at `https://kartaview.org/details/<sequence>`.
Only photos that KartaView reports as face/plate-blurred were used.
