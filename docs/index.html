Street-level greenery, sky and built density in Singapore

Independent personal project by Wenjie Luo, not affiliated with the Singapore-ETH Centre or the NUS Urban Analytics Lab. Code MIT; derived data CC BY-SA 4.0.

Repository and README Write-up (PDF) Survey protocol Pairwise survey (demo, collects nothing)

Each dot is a 250 m grid cell with KartaView images that we segmented with Mask2Former (Mapillary Vistas). Colour = mean green view index; ringed dots = "softened density" candidates (top-quartile planned floor-area intensity, greener than density predicts, and at least median sky view). Click a dot for its values.

Imagery-derived values: KartaView contributors, CC BY-SA 4.0. Density: URA Master Plan 2019 Land Use and HDB Existing Building (data.gov.sg, Singapore Open Data Licence v1.0). Basemap © OpenStreetMap contributors.
